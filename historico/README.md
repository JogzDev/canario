# Histórico

Fotografias datadas de um estado que já passou. Cada arquivo aqui foi verdade no
dia em que foi escrito e **não é mais** a descrição do projeto.

O estado atual mora em [`../ESTADO.md`](../ESTADO.md). Se algo aqui contradizer
o ESTADO, o ESTADO ganha.

Estes arquivos não foram apagados de propósito. Eles explicam **por que** o
projeto é como é — que decisão foi tomada, com que informação, em que dia. Isso
não dá para reconstruir do código, e já custou caro: em 08/2026 alguém quase
"corrigiu" o bundle do app de volta para um valor sem perfil de distribuição,
porque a razão da troca só existia numa conversa.

Regra ao mexer aqui: **não atualize**. Documento de histórico que recebe correção
deixa de ser histórico e vira mais uma fonte de verdade concorrente — que é
exatamente o problema que a pasta resolve. Se a informação mudou, o lugar da
mudança é o `ESTADO.md`.
